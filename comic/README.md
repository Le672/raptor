# Yukino 番剧放映室

独立动漫站：https://comic.yukino.bond 。沿用 Yukino Novel 的侧栏、浅色卡片和夜间主题，只保留返回主站链接。

## 功能

- iKun、暴风、非凡、量子四源搜索；动漫分类采用各源明确分类白名单，按番名与年份合并结果。
- 分类、年份、状态和排序；源站结果分批读取，每批再分页显示。时间明确区分目录同步与源站更新。
- 剧集详情、集数筛选、站内 HLS / MP4 播放、倍速、剧场、画中画、全屏、下一集、自动连播和片头跳过。
- 追番架、更新检查、历史、5 秒周期及暂停/离开时保存进度；JSON 导入导出按更新时间合并。
- 2026-10-31 起由独立 VPS 服务提供页面、接口和本地 SQLite 缓存，每小时第 20 分钟同步四源快照，分类与搜索缓存 5 分钟。失败源保留最多七天的旧目录并标记原同步时间，全部刷新失败或快照超过 8 MiB 不保存。收藏、观看进度和离线目录继续保存在原域名的浏览器中，视频需要网络。
- 目录、搜索和详情公开，播放入口、所有视频请求和手动刷新需主站登录；安全回跳保留当前页面，未登录或旧签名地址不能绕过验证。每账号每分钟 120 次播放操作、30 次手动刷新，没有每日上限；清单、密钥、分片及拖动请求不消耗操作次数。
- 播放地址由服务端从作品目录产生，12 小时 HMAC 签名；支持递归 HLS 清单、AES key、Range 和流式分片，不接受任意用户 URL。签名密钥在服务器的独立 SQLite 中，不写入代码、公开部署配置或日志。

## 本地与发布

仓库根目录运行 `npm run comic:dev`，打开 http://127.0.0.1:5187 。`npm run comic:test`、`npm run comic:build` 检查服务端、浏览器数据和构建。

构建与维护见 [VPS 部署说明](../vps-content/README.md)。推送后统一工作流检查并打包三个内容站，不再部署旧 Worker；服务器从本机已有 SSH 配置更新。原域名通过 Tunnel 接入，主站导航及更新日志继续通过原 Pages 工作流发布。

番源会变更、限区或返回失效地址；目录正常不等于每集视频正常。播放器逐集检测清单，显示真实错误并提供搜索换源。源码与目录验证不能替代 Chrome 实际解码和时间推进验证。
