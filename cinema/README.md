# Yukino 影视馆

独立影视站：https://cinema.yukino.bond 。沿用 Yukino Novel 的侧栏、浅色卡片和夜间主题，只保留返回主站链接。

## 功能

- iKun、暴风、非凡、量子、金鹰、魔都、红牛、大众八源搜索；分别校验电影、电视剧、综艺和纪录片的分类编号与名称，按片名、年份、类型合并结果。各源未单列的题材显示不支持，新增源的收藏、进度与备份和旧源兼容。
- 支持电影题材和剧集地区筛选、年份、状态及排序。每源每次最多请求三个实际子分类，未选题材时先轮转其余题材再读取下一源站页；页面明确标注当前批次，避免把首个子分类误当完整电影目录。
- 电影正片与版本选择、剧集目录筛选、站内 HLS / MP4 播放、倍速、剧场、画中画、全屏、下一集和自动连播。片头跳过仅作用于电视剧，电影不自动切换至其他版本。
- 片单、更新检查、历史、5 秒周期及暂停/离开时保存进度；JSON 导入导出按更新时间合并。
- 独立 Worker、KV、本机存储和带站点标识的备份，和番剧站数据分开。首页目录每 60 分钟同步（每小时整点），分类及搜索在运行实例中缓存 5 分钟；八源首页合为一份快照，每轮最多 1 次、每天最多 24 次 KV 写。快照中的条目保留原始时间、最多七天，兼容只读旧版分源缓存；部分源失败保留其旧数据，全部源失败或快照超过 8 MiB 不写入。访客首页、搜索、详情和手动刷新均不写 KV，额度耗尽时仍可返回成功获取的实时结果。
- 目录、搜索和详情公开，播放入口、所有视频请求和手动刷新需主站登录；安全回跳保留当前页面，未登录或旧签名地址不能绕过验证。每账号每分钟 120 次播放操作、30 次手动刷新，没有每日上限；清单、密钥、分片及拖动请求不消耗操作次数。
- 浏览器离线保留最近 80 份已浏览目录与应用外壳，视频需要网络。
- 播放地址由服务端从作品目录产生，12 小时 HMAC 签名；支持递归 HLS 清单、AES key、Range 和流式分片，不接受任意用户 URL。签名密钥在专用 KV 中，不写入代码、部署配置或日志。

## 本地与发布

仓库根目录运行 `npm run cinema:dev`，打开 http://127.0.0.1:5188 。`npm run cinema:test`、`npm run cinema:build` 检查服务端、浏览器数据和构建。

推送 master 中的 cinema 文件触发 `.github/workflows/deploy-cinema.yml`，使用现有 Cloudflare GitHub Secrets 自动创建独立缓存、绑定域名并发布。主站导航及更新日志通过原 Pages 工作流发布。

片源会变更、限区或返回失效地址；目录正常不等于每集视频正常。播放器逐集检测清单，显示真实错误并提供搜索换源。源码与目录验证不能替代 Chrome 实际解码和时间推进验证。
