# Yukino Novel · 轻小说书房

独立轻小说网站，正式入口为 https://novel.yukino.bond 。沿用 Yukino 品牌与视觉，导航围绕轻小说书房并提供返回主站入口；使用主站现有 React、Vite 和 lucide-react 依赖。2026-10-31 起页面、接口、同步和缓存迁至 VPS，原域名通过 Cloudflare Tunnel 接入。书目、介绍、目录与搜索公开浏览；章节正文与手动同步需要 Yukino 主站账户登录，登录后返回原页面。

## 本地运行

从仓库根目录执行：

```powershell
pnpm install
pnpm novel:dev
```

在 Chrome 打开 http://127.0.0.1:5186 。本地服务通过已配置的 HTTP(S) 代理访问公开书源，缓存保存在忽略的 `.novel-work/local-kv`。生产使用 VPS 的本地 SQLite，不消耗 Cloudflare KV。

```powershell
pnpm novel:test
pnpm novel:build
```

## 安装为应用与登录

访问 `/install` 查看 iOS／iPadOS、安卓和电脑安装步骤。Chrome 支持时显示安装按钮；iOS 使用 Safari 的“分享 → 添加到主屏幕”。清单包含 PNG、maskable 和 Apple 图标及书架、足迹快捷方式。更新由用户点击提示应用，只替换应用外壳，不清理书架与进度；离线正文仍受原登录策略限制。

`/login` 在书房自身窗口完成邮箱或主站账户登录，避免 iOS 独立存储无法接收外部浏览器会话。`POST /api/auth/login` 只向固定主站身份服务转发凭据，不跟随跳转，不将令牌返回前端；默认使用最长 7 天的 HttpOnly、Secure、SameSite=Lax Cookie。`POST /api/auth/logout` 清除当前存储空间的共享会话。两个接口严格检查同源 Origin，限流登录尝试，并由 VPS HTTP 适配器单独放行 POST。会话到期需重新登录；书架与进度仍是本机记录，不提供跨设备云端同步。

## 数据与更新

| 书源 | 搜索范围 | 目录与阅读 |
| --- | --- | --- |
| 哔哩轻小说 | [lnovel 公开聚合接口](https://github.com/yjl9903/lnovel/blob/main/examples/api.http)已索引的译文书库 | 分卷、正文、插图 |
| 轻之文库 | 源站当前返回的公开搜索结果 | 公开作品、分卷与正文 |
| 轻小说文库 | [公开书目索引](https://github.com/mojimoon/wenku8)与[官方站点地图](https://www.wenku8.net/sitemap.xml)交叉核对的书名、作者与标签 | 直接从源站读取公开目录与正文，受限时提供源站入口 |

- 各适配器独立编写，HTML 用 parse5 解析，文库 GBK 页面由 TextDecoder 解码，没有复制第三方解析器代码。页面结构、访问验证和源站状态可能变化，逐源显示失败、受限、旧缓存和最近成功时间。
- 最近更新页汇总哔哩与文库公开索引、轻之文库更新列表和已打开书目的公开元数据，不代表各平台全部作品。文库索引只接受官方站点地图存在且有真实书名的书号，重复记录保留最新日期；不依赖匿名受限的全站搜索，也不批量抓取数千本详情页。书目元数据来源为 MIT 授权的 mojimoon/wenku8 项目，正文仍使用源站接口。搜索统一筛选和分页，显示实际范围和数量，不写死总书量。
- VPS 计划任务每小时第 40 分钟同步更新列表，并对轻之文库、轻小说文库各轮流检查一本已知书目；书架每次最多检查六本新增书源作品，按上次成功获取时间轮换。目录与书目缓存 5 分钟、章节缓存 15 分钟，手动刷新最短 1 分钟。源站发布、翻译与上游缓存决定实际更新速度，不承诺与源站同步秒更。
- 本站同步时间、源站更新时间、上游抓取时间分别保留。失败时保留旧快照并明确显示原因和成功时间；空索引、登录 HTML、错误 JSON 不会覆盖成功快照。
- 原缓存接口由适配器转换为本地 SQLite：计划任务保存合并索引快照，固定包含索引、已知书目与源健康共六个键；搜索、详情、章节和图片响应使用有界内存与本地响应缓存，不访问 Cloudflare KV。相同服务实例合并计划任务并按小时去重。
- 索引记录从原始成功时间起最多保留 30 天，源健康 1 小时；只有成功数据比旧快照更新才持久化，全部书源失败或只有新的错误健康记录时不重写、不续期。临时内存上限 128 条 / 16 MiB，单条最多 8 MiB；本地响应缓存总量受限，搜索保留 1 小时、正文 7 天，读取缓存不会重置原始过期时间。浏览器书架和直达链接继续可用。缓存写入失败不把已成功获取的正文变成错误，定时持久化失败单独记录，设置页与 `/api/status` 返回最后成功快照时间和状态。
- 浏览器最近 180 个成功的公开 API 响应可在断网时回退。正文不再写入或回退浏览器响应缓存，升级时只清理原正文响应；需要联网验证登录后阅读，401 和手动同步失败均不会拿旧缓存冒充成功。书架、阅读进度、公开书目缓存与用户已下载的 TXT 文件保留。新增源章节明确拒绝访问时，服务端也不回退旧正文。Service Worker 缓存应用外壳；插图由普通浏览器 HTTP 缓存决定离线可用性。
- `done` 表示上游整理任务完成，不代表小说完结；连载状态只依据上游明确标签。
- 旧哔哩书号、缓存键和书架 schema 保持兼容，另外两个源使用 `linovel-`、`wenku-` 前缀，各源分开存进度；“其他书源”只给出匹配候选，需核对作者与目录，不猜测章节对齐。菠萝包已移除，旧书号与书源请求返回 410；升级清除其浏览器响应缓存和包含该源的聚合缓存，书架与足迹隐藏该源的旧记录，保留其他书目、设置、进度和登录信息。

## API

- `GET /api/books?source=all&q=关键词&tag=题材&status=ongoing&page=1&sort=updated`，`source` 可为 `all`、`bili`、`linovel`、`wenku`；分页固定 24 本，支持 `updated`、`title`、`new`（源内数字编号由新到旧）。
- `GET /api/books?ids=8,linovel-122429,wenku-1973`，为书架检查更新。
- `GET /api/book/:id`、`GET /api/book/:id/volume/:vid`、`GET /api/book/:id/chapter/:cid`。
- `GET /api/status`，索引数量、各源状态/范围/成功时间、最近同步和最新源站更新；`refresh=1` 请求检查。
- 图片代理仅允许三个书源已验证的 CDN 图片目录与栅格格式，不接受任意网址、端口、凭据或重定向。正文转成文字/图片块，由 React 渲染，拒绝外部脚本、事件属性和 iframe。

## 部署

构建和维护见 [VPS 部署说明](../vps-content/README.md)。统一工作流检查并打包三个内容站，使用本机已有 SSH 身份更新服务器；原 Worker 的计划任务和 workers.dev 入口停用，旧 KV 留作回退，不再用于线上请求。

部署包不包含账户凭据、线上数据库或用户内容。`verify-novel-live.mjs` 可检查网站外壳、逐源状态、真实中文搜索、公开目录与免费章节标注，并验证匿名正文和手动刷新返回 401 登录提示；该匿名检查不能代替真实账户登录后的正文验收。每次可见变更同步主站 `Changelog.tsx`。

书架与阅读足迹只在本机保存，不会上传给书源；备份仅含书目与进度。正文和插图权利归原作者与相关权利人，支持正版作品。
