## 正文写法

证据正文采用可以在案内实际调阅的形式：现场勘查、录像提取、逐项日志、技术工作单、移交目录、录音转录、批注、邮件与未发送的信。正文与摘要分别承担原始材料阅读和快速回顾，不把设计说明、解法指令或尚未完成的鉴定写成案内记录。

六人的口吻和关切分别落在具体生活中：许知微直接追问，也承认等待和家属立场会使她先入为主；沈砚惦记交班与工作，逐渐停止用忙碌淡化借卡；罗启明把个人选择包装成行政工作，面对原页仍试图限定责任；周予安说设备时简短准确，面对自己签名的底稿则失去这种从容；唐素关心空栏、旧页和手写更正；何闻记得箱子与潮气，对沉默八年的羞惭无法用“保存下来”抵消。

非关键支线扩写只呈现既定人物处境，没有新增能够改变凶手、时间窗口、门禁身份、断口来源或旧案责任的决定性事实。

## 不得改写的推理事实

- 20:14 广播来自 20:02 的录音。20:04 按正常工程安排配置播放，不等于当时已经计划杀人；周予安在袭击后利用既定播放制造误判。
- 顾承舟在 20:09:10 仍正常签收、走动。现场伤情意见只确认该致命伤会立即使人失去自主活动能力，不提供精确死亡秒数。
- 门禁读取卡，不读取人；内侧出门按钮不记录姓名。沈砚的卡由周予安借用，不能把卡的权限姓名直接当作入室者。
- 周予安 20:12:06 之后的连续录像真实，但没有覆盖此前袭击窗口。修复间行程不允许用录像开始时刻向前补全。
- 工作证须结合 20:08:54 原图的完整状态、死者掌部残片与工具袋缺角证件核对；不依靠认罪或单独一次颜色相似。
- 其余五人的排除依赖完整时段、通行结构和连续发现过程。20:18 首次开门画面先见倒地者，再有人跨过门槛。
- 旧案需分别证明原始停止请求、被替换的公开段落、周予安签名底稿、罗启明明确批注和独立接收记录。顾承舟错误签收、何闻长期沉默也保留在人物叙事中。
- 旧案证明范围为录音删改和由此转移责任的核心事实，不替代火灾全部成因调查或司法裁判。

## 数据与引擎约定

所有内容均从 `src/content.ts` 的具名导出读取。人物 ID 为 `xu`、`shen`、`luo`、`zhou`、`tang`、`he`；肖像键与人物 ID 相同。场景键与地点 ID 相同：`lobby`、`archive`、`studio`、`security`、`office`、`pump`、`transfer`。

| 字段 | 判定规则 |
|---|---|
| 证据或话题的 `requires` | 所列 E 编号全部已收集；不以认罪或推理结论作为证据取得条件 |
| 话题的 `statement` | 阅读该话题即可记录对应 S 编号；全部 24 条均有入口 |
| `challengeEvidence` / `challenge.evidence` | 可接受的相关证据备选，出示其中一项即可进入该命题的有限回应；出示物须已持有 |
| 推理的 `requiredSets` | 外层任选一组，组内全部满足；无关附加证据不抵消充分组合 |
| 推理的 `prerequisites` | 所列 D 编号全部完成 |
| 章节的 `required` | 所列 E 或 D 编号全部满足后进入下一章 |
| 时间线的 `requires` | 所列 E 编号全部持有后显示 |

单项质询的回应只处理该项证据足以反驳的部分。需要多份前提的完整比较另有要求齐备的后续话题，避免通过出示一张材料提前得知尚未取得的事实。

E22 工具袋证件的可查条件是 E09、E11、E20、E21 已收集：调查已有门禁、借卡、故障完结与原图依据，才进一步核对证件。它不依赖 D03、D04 或周予安认罪。所有证据均有场景热点入口；E06 另可由许知微提供。

## 尾声与可恢复调查

`before-dawn` 对应今案证据链完成、旧案尚未完成核查的正式结果。`voice-remains` 对应今案与旧案核心证据都完成的正式结果。两者都不改变当晚发生的事实。E31 家书和 E32 未发送说明用于人物理解，不作为正确破案的必备前提。

`review` 用于证据不足或错误报告后的复核。正文指出需要回看材料，不写成另一套真凶结局；玩家可以回到调查继续完成证据链。
