Yukino Speed v1.0.8：节点复查、国内 CDN 与全球服务商扩充。

- 新增 183 个地址，停用 38 个复测未通过的旧文件。现有 484 个地址、61 个国家和地区、126 个服务商 / 文件提供方，119 个地址标注中国大陆；144 个通过网页跨域检查。
- 优先补充腾讯、腾讯云、阿里云盘、阿里云、字节剪映、钉钉、华为云、七牛云、哔哩哔哩、迅雷等公开文件；增加 RackNerd、HOSTKEY、Hetzner、软件 CDN 及 LOOKING.HOUSE 第三方服务商测试目录。
- 增加服务商组合筛选，网页版默认只展示跨域通过的地址。四运营商与 Steam 完整文件继续保留；需要来源头的源仅供 Windows 使用。
- 修复 Windows 对来源头的处理：通过原生请求事件设置，并按请求隔离、跟随跳转和及时清理，避免 Chromium 拦截需要公开来源页的下载文件。
- 20 个未通过持续下载验收的候选暂缓收录，详细原因保留在核验记录。
- 保存实际读取、CORS、Range、核验时间及停用原因，见 SOURCES.md 和 data/source-health.json。核验来自单一网络环境，源站可能调整限制，不保证所有地区随时可用。
- 下载带宽曲线支持鼠标悬停、手机触摸和键盘查看采样时间、Mbps 与字节速度；横轴按实际采样时间绘制。
- 点击或触摸后保留所选点，不会因焦点跳到末尾；键盘查看时读数持续显示。
- 网页下载移到独立 Worker，切换标签页后临时错误继续重试。断网、冻结、刷新或回收恢复时继续同一任务和剩余配额；手动暂停保持暂停。
- 任务设置与实时监测面板的上下边缘对齐，曲线自动利用可用高度；手机继续采用单列布局。
- Windows 支持断网与系统挂起后的原任务恢复，界面版本读取实际程序版本。

手机系统可冻结或回收浏览器，无法保证挂起期间持续下载；恢复页面后自动续传。完整地址、兼容性与实际读取证明见 SOURCES.md 和 data/source-health.json。不支持 Range 的源可能超出一个实际数据块，全部计入。
