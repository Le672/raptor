Yukino Speed v1.0.1：网页版与 Windows 原生流式下载客户端。

修复任务成功上报后凭据丢失的问题：后续检查点、暂停恢复、结束和重新打开使用相同任务身份，统计只计新增流量。兼容 v1.0.0 已确认的重复记录，单个任务同步失败不会阻塞其他任务。

全站统计可在独立域名暂时无法连接时自动使用 Pages 备用接口，两者共用同一份持久数据库。

- 自选服务器、运营商节点目录、Steam / 游戏 CDN 完整文件链接，支持 1–32 线程。
- 定时测速、持续消耗、暂停 / 继续、流量配额和共享带宽上限。
- 实时网速、Mbps、持续时间、实际字节、带宽曲线及平均 / 峰值。
- 本机历史、JSON 导出与持久全站匿名上报统计，重复上报不重复计量。
- Windows 支持 HTTP 和无 CORS 下载目标；网页受服务器 CORS 和 HTTPS 限制。

下载 `*-setup.exe` 安装，或直接运行 `*-portable.exe`。`SHA256SUMS.txt` 提供校验值。此发行未配置代码签名。

流量为应用读取的有效载荷，不含协议开销与取消时的预读；限速为共享上限，瞬时速率存在波动。详情见 README。
