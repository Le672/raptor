Yukino Speed v1.0.4：全球节点与后台恢复。

- 新增 135 个实测地址，现有 339 个地址、58 个国家和地区；169 个支持网页下载。增加 DataPacket、EDIS Global、Psychz、Clouvider 全球机房，保留四运营商和 Steam 内置源。
- 下载带宽曲线支持鼠标悬停、手机触摸和键盘查看采样时间、Mbps 与字节速度；横轴按实际采样时间绘制。
- 网页下载移到独立 Worker，切换标签页后临时错误继续重试。断网、冻结、刷新或回收恢复时继续同一任务和剩余配额；手动暂停保持暂停。
- 任务设置与实时监测面板的上下边缘对齐，曲线自动利用可用高度；手机继续采用单列布局。
- Windows 支持断网与系统挂起后的原任务恢复，界面版本读取实际程序版本。

手机系统可冻结或回收浏览器，无法保证挂起期间持续下载；恢复页面后自动续传。完整地址、兼容性与实际读取证明见 SOURCES.md 和 source-audit.json。不支持 Range 的源可能超出一个实际数据块，全部计入。

提供 setup.exe、portable.exe 和 SHA256SUMS.txt，发行未配置代码签名。
