# Workers KV 写入预算

Cloudflare 免费 KV 的每天 1,000 次写入额度由整个账号共享，不是每个站点或命名空间各有 1,000 次。限额在 UTC 00:00（新加坡/北京时间 08:00）重置，已经消耗的次数不能由部署清零。

## 内容站预算

| 服务 | 每小时任务（UTC） | 每次最多写入 | 正常计划每日最多写入 |
| --- | --- | ---: | ---: |
| 影视馆 | 整点 | 8 个片源合为一份快照 | 24 |
| 番剧放映室 | 第 20 分钟 | 4 个番源合为一份快照 | 24 |
| 轻小说书房 | 第 40 分钟 | 7 个固定索引/状态键合为一份快照 | 24 |
| 合计 | | | **72** |

首页、搜索、详情、正文、封面和手动刷新不会持久写入 KV。内容站的临时数据放在有界内存或 Cache API；Cache API 不属于 Workers KV。定时任务只保存固定首页/索引快照，源站失败时保留旧快照原时间，过期数据不冒充新数据。已有 KV 键不删除。

72 是当前正常计划的上限，不是整个账号的实时计量；跨实例重复投递任务、管理员操作、邮箱和其他远端 Worker 仍可能额外写入。账号剩余预算应优先留给邮箱登录、设置和附件，不能因为每个内容站单独低于 1,000 就认为账号安全。

`npm run kv:budget` 检查三个配置只保留每小时一次任务，并将内容站的合计预算限制为每天 100 次以内。三个内容站部署前都会执行；各站服务测试实际统计定时任务和访客接口的 KV 写入次数。新增片源或提高频率前必须复核合计预算。

影视馆与番剧的 `home-snapshot:v2` 保存整站首页快照，每次最多一写；缺少合并快照时只读旧的源/分类键。部分源失败时保留其原有记录和时间，内层条目七天过期，不因外层快照保存而续期；全部源失败不写入。UTF-8 序列化超过 8 MiB 时跳过保存并告警，不拆成多次写入。

邮箱的图表统计使用最多 32 个时区的十五分钟内存/Cache API 缓存，定时任务不再遍历和重写统计 KV 键；每日发件总量从已有 D1 邮件记录计算，不再每封发件写 KV 计数。历史 KV 数据保留，真实账号发送限制仍由原有数据库逻辑执行。

邮箱对同一用户同一天的会话续期合并并发请求，有界保留最近 256 位用户，写入失败退避 60 秒。仍有效且未撤销的会话不因续期写入失败而失去访问；新登录、退出和真实发送配额仍必须成功保存。此处也是实例内去重，不能承诺全球每位用户每天严格只有一写。

## 超额当天的行为

成功取到的实时目录和正文照常返回，KV 保存失败单独记录，不能把成功阅读变成接口错误。仍可读取的旧快照作为失败回退，并显示其实际检查时间。轻小说状态页分别报告上次成功持久化时间和当前保存失败原因。

不使用 KV 为每个请求记录限速或点击数，也不通过自动注册/拆分账号规避配额。登录门槛不会减少后台 Cron 写入，因此保留上述写入预算。邮箱登录本身仍可能写入邮箱 KV，内容子站复用主站会话，避免频繁重新登录。

## 内容站登录与宽松限速（2026-10-21）

目录、搜索、作品详情、分卷目录和封面公开。影视馆/番剧的播放入口、所有媒体请求、小说章节正文、以及 `refresh=1` 主动刷新均需主站会话；直接调用接口或拿到旧签名视频地址也不能绕过。子站页头和拒绝提示提供主站登录入口，安全回跳只允许三个内容站的 HTTPS 地址。

主站签发 `HttpOnly; Secure; SameSite=Lax; Domain=yukino.bond` 会话 Cookie，生命周期不超过原有七天 JWT。子站将会话提交至主站 `/api/auth/access`，由主站验证签名、期限及 D1 中的当前账号；子站不持有主站或邮箱签名密钥。验证成功只在有界内存复用最多五分钟且不超过 JWT 到期时间，验证服务不可用时返回 503，不冒充退出或放行；会话和限速均不写 KV。浏览器退出后不再携带会话，媒体响应禁止缓存，旧章节浏览器缓存迁移清理。

每个内容站、每个账号每分钟允许 **120 次**播放入口/章节操作，另有 **30 次**主动刷新预算，等待最多一分钟后自动恢复；没有每日额度。HLS 清单、AES 密钥、视频分片和 MP4 Range 请求只验证登录，不消耗操作次数。书架/收藏/进度及用户自行下载的文件保留。公开目录仍保留原有访客 IP 防刷。

这是边缘实例内存中的温和防突发措施，并非跨全球实例严格计费的限额。部署和冷启动可能重置计数，限制不作为持久账户配额承诺。KV 主要节省仍来自固定快照和每小时 Cron，登录门槛用于减少匿名批量抓取。
