# 域名导航与访问量

`speed/src/site-routing.mjs` 是主站、独立测速站、浏览器链接和 Pages middleware 共用的域名规则。各功能路径指向已配置的独立子域；首页、笔记、登录、注册和管理台属于 `www.yukino.bond`。开发预览和原生壳保持本地路由。查询参数、片段与铁路功能深链保留，API、静态文件与铁路地图数据不参与页面跳转。跨域使用浏览器原生链接，同域仍采用 React Router。

Pages 对错误域名的页面入口进行 308 跳转，浏览器入口同样检查，以覆盖缓存页面和 SPA 导航。`/speed` 旧入口例外：先在原域名读取本机流量与待同步任务，保留任务 ID 和凭据补报至正式测速接口，再进入独立站；失败时保留数据并提供重试和继续访问。流量 API 接受 Yukino 自有 HTTPS 子域，拒绝无关来源。历史仍保留在原浏览器域名，累计流量由共享 D1 数据库合并，重复任务采用最大检查点不会重复计量。

`/api/visits` 与主站首页、页脚展示主站公开页面的累计浏览次数（PV），不是独立访客数。每次打开、刷新、切换主站公开页面生成新的随机事件 ID；同页筛选、React 重挂载、同事件的重试不重复计数。登录和管理页面以及独立子域不新增主站计数，子域页脚仅读取总量。

总量保存在 `site_visit_total`，自表首次启用起累计，不估算上线前的历史。`site_visit_events` 只保存随机 ID 和时间；SQLite 插入触发器原子递增总量，同 ID 的重复请求不递增。初始化时清理七天前的去重事件，总量不会被清理。没有存储访问者 IP、ASN、账号、浏览路径或浏览器特征。公开客户端统计不能等同于精准的人类访客统计。
